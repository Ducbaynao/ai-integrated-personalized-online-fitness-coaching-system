## Required port contract before enabling erasure

For each owning domain, use `(userId, erasureRequestId)` for immediate idempotent concealment, then `(userId, erasureRequestId, claimToken)` for fenced minimization/attestation in short transactions. The result must enumerate unresolved field groups and media IDs with provider/bucket/key, verified single ownership and link count; retain source IDs and counterpart facts. An attestation may report `COMPLETE` only after persisted field/object checks, not merely because a method returned. Recheck mandatory hold and request lease before any irreversible action. Do not hold a DB transaction across S3; an in-flight delete cannot be recalled if a hold arrives during the call. A failed/ambiguous owner or storage verification keeps the request retryable or `DOMAIN_REVIEW_PENDING` and blocks `ACTIVE_DATA_CLEANED`.
