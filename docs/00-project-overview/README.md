# Project overview

The platform brings coaching, workouts, scheduling, measurements, progress, nutrition, communication, and AI assistance into one system.

Students may train in `SELF_DIRECTED` mode or work with a trainer in `HUMAN_COACH` mode. Coaching authority is recorded by coaching period so transitions never erase historical fitness data.

AI analyzes authorized, quality-aware context and creates recommendations for the responsible human. It does not activate goals, plans, or nutrition targets by itself.
