### 3.1. Các Hạng Mục Đã Khép Hoàn Toàn Về Mặt Kỹ Thuật (Technical Verification Passed)
- **Hợp đồng Typed Change Set F03:** Đạt 100% JSON schema validation (32/32 fixtures PASS).
- **Quyền hạn Authority Model:** Phân định độc lập 4 tầng (Generate, Read, Accept, Reject); kiểm tra `ACTIVE` account và coaching context đa thời điểm.
- **Thực thi Volume Adjustment Hoàn Thiện:**
  * Áp dụng đầy đủ giá trị cho cả `sets + reps` và `sets + duration` (kiểm tra chi tiết `before_value` và `after_value` trong PostgreSQL).

  * Idempotent replay: trả `replayed = true`, không tạo bản ghi trùng lặp trong `workout_session_adjustments` hay `ai_recommendation_applications`.

  * *Ca 1:* Khi sub-command thứ hai trong chuỗi điều chỉnh thất bại $\to$ domain command thứ nhất đã ghi vào PostgreSQL bị rollback hoàn toàn (version về 1, adjustments count = 0, command receipts = 0, domain audit = 0).

- **Concurrency & Idempotency Guards:** Đạt 100% tests cho Stale Target, Idempotency Replay và Double Accept.
- **Client Mobile Quality:** Đạt 41/41 tests Jest/RNTL (units, bodyweight, state isolation, commandKey retry).
