## Review rule

Nếu tài liệu nguồn thay đổi một trong các mục trên, review tối thiểu các file `screen-inventory.md`, `component-specifications.md`, actor flows/screens và `traceability-matrix.md`. Nếu thay đổi authority hoặc lifecycle, cập nhật thêm skill reference `domain-invariants.md`.
