# UI Review Checklist

## Product correctness

- [ ] Actor and authority are correct.
- [ ] Coaching Mode is not confused with AI Assistance.
- [ ] Proposal, version and transition states are represented correctly.
- [ ] History is preserved and discoverable.
- [ ] Appointment/workout and target/actual pairs remain separate.
- [ ] Missing/partial/estimated data is labeled.
- [ ] Alert and AI recommendation are visually and behaviorally distinct.

## Visual consistency

- [ ] Shared tokens and components are used.
- [ ] DM Sans, purple brand and semantic status colors match the specification.
- [ ] Spacing follows the 2/4/8/12/16/24/32 scale.
- [ ] Mobile screen padding is consistent.
- [ ] Admin Web uses appropriate information density rather than mobile cards everywhere.

## States and accessibility

- [ ] Loading, empty, error and permission states exist where applicable.
- [ ] Touch targets and contrast meet the accessibility rules.
- [ ] Forms have labels, units, helper text and accessible errors.
- [ ] Charts have textual alternatives.
- [ ] Keyboard and focus behavior work on Admin Web.

## Final comparison

- [ ] Screen inventory and traceability matrix remain accurate.
- [ ] No template text, brand or unauthorized image was copied.
- [ ] No unsupported business behavior was inferred from the visual reference.
