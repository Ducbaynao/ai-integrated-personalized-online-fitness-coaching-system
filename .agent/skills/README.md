# Project agent skills

Project-specific reusable skills live in this directory. Repository-wide constraints and routing remain in the root `AGENTS.md`.

- Load `digital-fitness-core` for every project task.
- Load the focused domain/client skill for the area being changed.
- Load `digital-fitness-ui` for Mobile/Admin screens, navigation, design-system, accessibility, or Figma-to-code work.

The repository uses `AGENTS.md` routing so Codex can apply these skills even when `.agent/skills/` is not included in the runtime's native skill catalog.
