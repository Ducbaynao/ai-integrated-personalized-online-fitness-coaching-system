# Mobile Design System

Các token trong `tokens` là nền tảng dùng chung cho Student và Trainer mobile. Khi project đã có theme/tokens, hãy map các giá trị vào kiến trúc hiện tại thay vì tạo hai hệ thống song song.

Component được khuyến nghị:

- AppButton
- AppTextField
- ScreenHeader
- MobileBottomNavigation
- StatusBadge
- MetricCard
- GoalProgressCard
- WorkoutCard
- NutritionSummaryCard
- AttentionSignalCard
- AIRecommendationCard
- ProposalCard
- DataQualityBadge
- TimelineEvent
- EmptyState

API và trạng thái của component được mô tả tại `docs/ux-ui/component-specifications.md`.
